# ترب برای خرید لپ‌تاپ دست‌دوم

[نسخهٔ آنلاین](https://torob.alirezashamsaei.ir/) · [چالش مهندس محصول هوش مصنوعی ترب](https://jobs.torob.com/ai-product-engineer) · [English](README.md)

راهنمای فارسی خرید لپ‌تاپ دست‌دوم که پیشنهادهای فروشگاه‌ها را بر اساس نیاز، بودجه و ایرادهایی که خریدار می‌تواند بپذیرد، مرتب می‌کند.

## ۱. مسئلهٔ واقعی خریدار

با سخت‌تر شدن خرید کالای نو برای بسیاری از خریداران در ایران، رشد بازار دست‌دوم را یک فرصت دیدم و از لپ‌تاپ شروع کردم. خرید دست‌دوم دو دشواری اصلی دارد. اول **اعتماد** است. دو آگهی برای یک مدل ممکن است به دو دستگاه با فرسودگی، وضعیت باتری و شرایط تست متفاوت مربوط باشند. دوم **تعداد زیاد گزینه‌ها** است. مقایسهٔ ده‌ها آگهی از فروشگاه‌های مختلف وقت می‌گیرد و حتی بعد از آن هم سخت است بدانید بهترین گزینه را برای نیاز خودتان پیدا کرده‌اید یا نه.

بررسی آگهی‌ها هم ایرادهای مشخص دستگاه‌ها را نشان داد و هم جاهایی را که اطلاعات کافی دربارهٔ وضعیت دستگاه وجود نداشت. گام بعدی برای سنجیدن نحوهٔ تصمیم‌گیری خریداران، مصاحبه و آزمون کاربردپذیری است. [گزارش بررسی منابع](torob-stock-laptop-source-audit.md)

## ۲. ایدهٔ متمایز

راهنما الگوی مقایسهٔ بین فروشگاه‌ها در ترب را برای لپ‌تاپ دست‌دوم به کار می‌گیرد. از خریدار می‌پرسد لپ‌تاپ را برای چه کاری می‌خواهد، سقف بودجهٔ دستگاه چقدر است، چه چیزی برایش اولویت دارد و آیا خط‌وخش بدنه را می‌پذیرد. برای بازی و کار گرافیکی، نام بازی یا نرم‌افزار و سطح عملکرد مورد انتظار هم پرسیده می‌شود.

خریدار می‌تواند تعیین کند چه میزان فرسودگی برایش قابل قبول است و همان‌جا در نتیجه، انتخابش را عوض کند. نسخهٔ اول روی خط‌وخش بدنه تمرکز دارد و در صورت نیاز، شدت قابل قبول را هم می‌پرسد. اطلاعات وضعیت هر دستگاه به آگهی خودش متصل می‌ماند و دو دستگاه از یک مدل می‌توانند در کنار هم نمایش داده شوند.

## ۳. داده و رتبه‌بندی بر اساس نیاز خریدار

از ۱۲۰ آگهی بررسی‌شده، ۴۲ آگهی از هفت فروشنده از بررسی اولیه گذشتند. برنامه این مجموعهٔ بررسی‌شده را از SQLite می‌خواند. قیمت و موجودی مربوط به زمان ثبت آگهی است. به‌روزرسانی خودکار در برنامهٔ توسعهٔ بعدی است. [گزارش بررسی منابع](torob-stock-laptop-source-audit.md)

پیش از رتبه‌بندی، پیشنهادها بر اساس بودجه، اطلاعات مستند، حداقل سخت‌افزار و ایرادهای قابل قبول فیلتر می‌شوند. اولویت خریدار بیشترین وزن را دارد و کامل بودن اطلاعات هم در رتبه اثر می‌گذارد. رده‌های سخت‌افزاری برآوردی از تناسب دستگاه با کاربرد هستند. [مبنای رتبه‌بندی](docs/ranking-baseline.md)

دو مسیر بررسی‌شده در نسخهٔ آنلاین:

- **کار اداری با ۱۵۰ میلیون تومان.** با پذیرش خط‌وخش بدنه، ۲۷ پیشنهاد مناسب پیدا شد. با [اولویت قیمت](https://torob.alirezashamsaei.ir/guide/review?verdict=1&usecase=office&budget=150000000&priority=price&defect.chassisScratch=acceptable)، مدل HP ZBook 14 G2 اول است. با [اولویت عملکرد](https://torob.alirezashamsaei.ir/guide/review?verdict=1&usecase=office&budget=150000000&priority=performance&defect.chassisScratch=acceptable)، مدل Dell Latitude 5490 به رتبهٔ اول می‌رسد.
- **Counter-Strike 2 با انتظار عملکرد متعادل و بودجهٔ ۱۰۰ میلیون تومان.** در [نتیجهٔ بازی](https://torob.alirezashamsaei.ir/guide/review?verdict=1&usecase=gaming&requirement=cs2&expectation=balanced&budget=100000000&priority=performance&defect.chassisScratch=acceptable) هیچ پیشنهاد سازگاری پیدا نشد. پنج گزینه به‌عنوان جایگزین نمایش داده می‌شوند و هر کدام مشخص می‌کند که قیمت دستگاه از بودجه بالاتر است.

## ۴. توضیح پیشنهادها و تصمیم‌های محصول

هر کارت دلیل پیشنهاد، لینک فروشنده، قیمت دستگاه، تاریخ بررسی، ایرادهای اعلام‌شده و شرایط تست را در صورت وجود نشان می‌دهد. اگر خریدار شرطی دربارهٔ وضعیت دستگاه داشته باشد، برای احراز آن شرط مدرک لازم است. سایر جزئیات اعلام‌نشده همچنان با برچسب نامشخص نمایش داده می‌شوند. هر جایگزین می‌گوید با کدام شرط سازگار نیست. توضیح فعلی هر پیشنهاد را جداگانه شرح می‌دهد. گام بعدی این است که دلیل برتری پیشنهاد اول بر دوم مستقیماً توضیح داده شود.

## ۵. پیاده‌سازی کامل و تجربهٔ کاربری

نسخهٔ آنلاین با Next.js ساخته شده و از راهنمای گفت‌وگومحور فارسی و راست‌به‌چپ، فیلتر و رتبه‌بندی سمت سرور، SQLite و Docker استفاده می‌کند. خریدار می‌تواند بودجه، اولویت و ایرادهای قابل قبول را از صفحهٔ نتیجه تغییر دهد. در بررسی انتشار، هر ۷۷ آزمون خودکار، بررسی TypeScript و ساخت نسخهٔ تولید موفق بود.

## ۶. استفادهٔ عملی از هوش مصنوعی

تمام این پروژه را با ChatGPT Codex پیش بردم، از تحقیق و تعیین محدودهٔ پروژه تا بررسی داده‌ها، طراحی، پیاده‌سازی و آزمون. برای فرایند مهندسی نرم‌افزار از مجموعه مهارت‌های مت پاکاک (Matt Pocock) و برای طراحی بصری از Impeccable و Taste استفاده کردم.

در بازبینی آگهی‌ها، ادعاهای متناقض یا ناقص را با صفحهٔ فروشنده و شرایط فروش تطبیق دادیم و آگهی‌هایی را که شواهدشان کافی نبود، کنار گذاشتیم. نسخهٔ آنلاین با قواعد ثابت و قابل بررسی رتبه‌بندی می‌کند. مقایسهٔ پیشنهادی با SubQ هنوز انجام نشده است. ## اجرای محلی

از Node.js نسخهٔ ۲۲٫۱۳ یا جدیدتر استفاده کنید.

```sh
npm ci
npm run seed:offers
npm run dev
```

[localhost:3000](http://localhost:3000) را باز کنید. برای بررسی پروژه، دستورهای `npm test`، `npm run typecheck` و `npm run build` را اجرا کنید.

```sh
docker build -t torob-challenge .
docker run --rm -p 127.0.0.1:3000:3000 torob-challenge
```
